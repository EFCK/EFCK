# Efe Can Kırbıyık

Machine learning engineer at [Poilabs](https://www.poilabs.com), B.Sc. in Artificial Intelligence and Data Engineering from Istanbul Technical University (2026).

I work on floor plan understanding for indoor maps: panoptic symbol spotting on vector CAD drawings, test time domain adaptation so models hold up on buildings they were never trained on, and patch wise segmentation of raster plans. Before that I spent a year on a TÜBİTAK project applying interpretable machine learning to UK Biobank retinal imaging for Alzheimer's disease prediction.
